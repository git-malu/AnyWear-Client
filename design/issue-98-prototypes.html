Keep the result area stable and announce “Creating your preview” with a restrained progress cue.

If generation fails

Show a plain-language reason and the existing Retry action, with an announced error state.

When complete

Show the result, rating and try-again action; preserve the selected outfit for comparison.

Can I interpret progress?

Progress is calm and announced without inventing a cancel control or a completion-time promise.

Can I compare the result?

Reference and preview receive equal image space; the result retains existing rating and retry capabilities.

What if it fails?

Keep the existing failure message and Retry recovery path; improve its hierarchy and announcement semantics.

Evaluation is source and prototype review, not user research, accessibility certification or device validation. Final changes must preserve existing API behavior, route structure and current product capabilities.
